文件迁移

把占空间的大文件夹搬到还有余量的盘：先复制 → 逐项校验（文件数 + 字节）→ 才替换为目录联接。原路径保持不变，PATH、快捷方式、注册表引用继续有效。

迁移前请关闭正在使用该文件夹的程序；被占用的文件会导致复制失败，此时不会改动任何源数据。
