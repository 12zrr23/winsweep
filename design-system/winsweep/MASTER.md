## 1. 核心色板（语义令牌）

| 令牌 | 浅色 | 深色 | 用途 |
| :--- | :--- | :--- | :--- |
| `--bg` | `#FFFCF2` | `#17141F` | 页面底色（叠加 18px 点阵纹理） |
| `--surface` | `#FFFFFF` | `#221E2E` | 卡片 / 侧边栏 |
| `--surface-2` | `#FFF7E3` | `#2B2639` | 次级面 / 列表行底 |
| `--ink` | `#14121A` | `#F7F4FF` | 主文字（对比 ≥ 15:1） |
| `--ink-soft` | `#4A4459` | `#C9C2DE` | 次文字（≥ 7:1） |
| `--ink-mute` | `#7A7390` | `#9A93B0` | 辅助文字（≥ 4.6:1） |

| `--shadow` | `#14121A` | `#08060D` | 硬偏移阴影色 |

| `--accent` | `#FFCE5C` | `#FFD97D` | 次强调（亮黄，激活态导航底） |

| `--violet` | `#6A7BB4` | `#98A6E0` | 第三强调 / 焦点环 |
| `--danger` | `#FF5A5F` | `#FF7A80` | 危险操作 |

| `--warn` | `#F5A623` | `#FFC15E` | 警告 |

浅色次要文字与黄/粉底上的文字均使用 `--*-ink`（近黑 `#14121A`）以保证 ≥ 4.5:1；
深色下所有强调底改用浅字/深字对应令牌，避免"亮色底 + 白字"的低对比陷阱。

## 2. 形状 / 间距 / 动效

- 圆角：`--r-sm 10px` / `--r-md 16px` / `--r-lg 22px`
- 描边：`--bd 3px solid var(--line)`（Memphis 记忆点：粗描边 + 硬阴影）
- 阴影：`--sh 6px` / `--sh-sm 4px` 无模糊硬偏移；hover 位移 `-2px,-2px` 并加深阴影，active 回落 `2px,2px`
- 动效：`--dur 180ms`，`--ease cubic-bezier(.34,1.4,.64,1)`（Q 弹）；`prefers-reduced-motion` 下全部降为 ~0
- 间距节奏：8px 基准（卡片 18–20px 内距，行间 10px，区块 16–18px）

## 3. 排版

- 标题/品牌：`Fredoka` 700，字号 16–30px，字距 -0.2 ~ -0.6px
- 正文/标签：`Nunito` 600–800，12–14.5px
- 数字（体积/百分比）：`Outfit` 500–900 + `font-variant-numeric: tabular-nums`，等宽对齐
- 中文回退：`Microsoft YaHei UI` → `Microsoft YaHei` → `system-ui`
- 字重纪律：同一层级只用一档字重；标签统一 800 + 大写/微字距

## 4. 组件规范

| 组件 | 规范 |
| :--- | :--- |
| 导航项 | 透明底 + 3px 透明描边；hover 米色底 + 硬阴影；active 亮黄底 + `rotate(-1.2deg)` + 5px 硬阴影 |
| 按钮 | 全圆角 999px、3px 描边、4px 硬阴影；主=粉、次=黄、危险=红、提权=紫 |
| KPI 卡 | 右上角 22% 透明度几何圆（青/粉/紫轮转），数值 38px/900 |
| 列表行 | `--surface-2` 底 + 2.5px 描边 + 16px 圆角，hover 微位移 |
| 复选框 | 22px、3px 描边、7px 圆角；选中填 `--primary` 并绘对勾；hover `rotate(-8deg)` |
| 标签 | 10.5px/800、2px 描边、`rotate(-2deg)` 贴纸感；颜色+文字双编码（不只靠颜色） |
| Toast | 右下角硬阴影卡，左侧状态圆点；4.2s 自动淡出 |
| 空态 | 2.5px 虚线框 + 居中说明 |

## 5. 无障碍与验收

- 文本对比：主/次文字 ≥ 4.5:1（实测主文字 ≥ 15:1）
- 非文本对比：描边、复选框、进度条 ≥ 3:1
- 焦点可见：`outline: 3px dashed var(--violet); outline-offset: 3px`
- 信息不依赖单一颜色：标签同时带文字（"可瘦身"/"活跃 <7天"/"需管理员"）
- `prefers-reduced-motion: reduce` 关闭动画与位移
- 响应式：≥1180 三列 → 960–1180 两列 → <960 单列且侧栏转顶栏

## 6. 反模式（禁止）

- ❌ 用 Emoji 当结构性图标（统一用内联 SVG 线性图标）
- ❌ 大面积霓虹渐变糊在文字后（可读性差）
- ❌ 圆角/描边/阴影数值随意漂移（必须走令牌）
- ❌ 只靠颜色区分状态
